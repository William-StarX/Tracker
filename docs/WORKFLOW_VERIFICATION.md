# 1.5.0 关键阶段调用验证

验证环境：Windows、Python 3.12.14、MCP SDK 2.3.0，2026-11-12。

- 两个组件分别 31 项通过、1 项跳过；跳过项为 Windows 未授权创建符号链接。
- 六种宿主配置实际启动后，官方 MCP 客户端在传统握手中收到与 SDK 工具目录相同的阶段指引；自动协商、MCP HTTP 也验证该指引。
- Skill 打包在 wheel 中；安装器可导出，保留现有定制，实际导出后的启动脚本可读取工具目录和运行安装的组件。
- 两个 Skill 均通过技能格式验证，启用隐式调用；本机 Codex 的 skills/list 返回两者为 user 范围且 enabled=true；通过安装后的入口运行 Commons Lang 审查/历史查询均成功。
- 完整报告仅排除顶层运行时间与生成时间字段，与先前对应报告一致；没有改动原分析引擎的 17 个随包源码/资源。
- RefactoringMiner 首轮有一次 MCP 初始化超时；同一代码整套复测通过。该次超时原因未确认，没有据此修改协议或放宽断言。

验证证明规则被正确打包、传递以及调用入口可运行，不证明所有模型会在每种提示下必然选择工具。真实宿主 GUI 的完整项目流程和强制调度器事件门禁没有在本次验证中实现或验收。参见 WORKFLOW.md。
